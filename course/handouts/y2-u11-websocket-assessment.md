# Exit ticket — WebSocket bidirezionale

Obiettivo: mantenere una connessione per comandi realtime.

1. So spiegare perché la connessione resta aperta?
2. So indicare chi invia ogni messaggio?
3. So descrivere cosa deve accadere alla chiusura?

4. Allega un'evidenza dell'esercizio base: Completa la conversazione ready→STOP→ack.
5. Descrivi un errore osservato e il cleanup eseguito. Il marker da solo non vale come evidenza.
