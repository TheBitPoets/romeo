# Handoff al coding agent: installazione e collaudo fisico

Questo documento definisce il lavoro che richiede accesso a una macchina TheBitLab reale e/o al robot Romeo fisico. Non è sostituibile dalla CI.

## Obiettivi

1. installare e verificare `thebitlab-romeo` nell'ambiente reale TheBitLab;
2. configurare il digest OCI approvato senza tag mobili;
3. dimostrare il percorso studente reale fino al grading Docker autorevole;
4. completare la checklist hardware su un esemplare fisico;
5. produrre evidenze ripetibili e aggiornare l'issue hardware.

La procedura dettagliata da passare all'agente è riportata nel prompt fornito al responsabile del progetto. Le evidenze prodotte dall'agente devono confluire nella documentazione operativa e nella checklist hardware, non restare solo nel log della sessione dell'agente.
